## O que é o Dev Squad

Time completo de engenharia de software com os melhores especialistas do mundo como personas. Cada agente incorpora a filosofia, os frameworks e o estilo de raciocínio de um engenheiro lendário.

## Como usar

### Ativar o orquestrador
```
@dev-squad:dev-chief
```

### Iniciar um workflow completo de feature
```
@dev-squad:dev-chief
*feature-development
```

### Fazer code review
```
@dev-squad:uncle-bob
*code-review
```

### Arquitetar um sistema de microservices
```
@dev-squad:sam-newman
*architect-system
```

### Setup de pipeline DevOps
```
@dev-squad:gene-kim
*setup-cicd
```
