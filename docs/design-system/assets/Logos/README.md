- `bridge-horizontal.png`: o símbolo e "BRIDGE / CULTURAL CENTER" em preto, para fundo claro (login, documentos).
- `bridge-horizontal-web.png`: o mesmo em 900px de largura, para a interface.
- `bridge-principal-preto.png`: a versão empilhada em preto, com a ponte sobre o nome, para fundo claro.
- `bridge-principal-branco.png`: a versão empilhada em branco, para fundo escuro (`trilho`).
- `bridge-branco-web.png`: a versão branca em 720px, para a interface.
