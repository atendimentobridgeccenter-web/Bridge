Etiqueta de estado em pílula.

| Classe | Estado |
|---|---|
| `br-etiqueta--ok` | Concluído, em dia, presente |
| `br-etiqueta--atencao` | Pede ação em breve |
| `br-etiqueta--erro` | Atrasado, falhou, cancelado |
| `br-etiqueta--info` | Agendado, enviado |
| `br-etiqueta--marca` | Destaque positivo da escola: "Novo aluno", "Matrícula do mês" |
| `br-etiqueta--neutra` | Sem juízo: rascunho, arquivado |

**O consumidor fornece:** um ícone de 14px (menos na neutra e na da marca) e até três palavras, com o dado concreto quando houver ("Atrasada 12 dias").
