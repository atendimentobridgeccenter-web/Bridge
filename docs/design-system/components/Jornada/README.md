Jornada: as etapas de uma pessoa (Contato, Avaliação, Matrícula, Em aula), ligadas por pequenos arcos de ponte.

**O consumidor fornece:** uma `ol.br-jornada` com até cinco `li`, cada uma com `.marco`, `.nome` e `.quando`. Use `data-estado="feito"` nas etapas concluídas (marco laranja com check) e `data-estado="atual"` na etapa em andamento. As futuras ficam sem atributo. O arco que chega a uma etapa fica laranja quando a anterior está feita.

**Onde usar:** no topo do perfil do contato e do aluno. Não use para processos internos da equipe.
