Resumo: até três números no topo de uma tela, em serifa grande, como os números do site ("500+", "92%").

**Composição:** colunas desiguais (1,5fr, 1fr, 1fr). O primeiro número, o mais importante, vai num cartão grafite (`escuro`), com o valor em laranja. Os outros vão em cartões claros. Use `marca` em `dd` para pintar de `laranja-texto` um número positivo da escola.

**O consumidor fornece:** `dt` (o que é), `dd` (o número) e `small` (o contexto: "de ¥ 452.800 previstos"). Número sem contexto não entra.
